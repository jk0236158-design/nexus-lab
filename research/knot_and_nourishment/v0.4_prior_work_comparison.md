## §0 起稿軸 (= v0.3 → v0.4 motivation)

v0.3 を 5/13 朝に起稿後、 Knot 研究軸の物理 fire は 4 日間 0 件で停滞 (= 5/17 status v0.1 §4-A drift 検出済)。 但し同期間に nokaze 全体としては大きな構造変化が起きた:

1. **5/13 夜 経営者 reform** (= jun reframe 「作業をするんじゃなくて経営をするって考えにしてほしい」、 4 段 reframe で Zen 役割が 「作業者 + PM 兼任」 から 「経営判断 + 戦略 + 組織 + 完了判定」 に shift)
2. **5/16 朝 jun 診断レポート + Kai 「claim → evidence」 critical reframing** (= 商品 narrative を 「AI company operation を claim として売る」 から 「actual AI company operation の evidence を売る」 に shift)
3. **5/16 17:46 委任権限 v1 確定** (= 8 自走項目 + 9 jun 確認必須項目 + 8 件 standing prohibition、 operating default = 「Proceed inside delegated authority and report afterward. Stop only at owner boundaries」)
4. **5/16 23:10 Kai Yuino autonomous action layer 接続** (= 「Jun に聞いて止まる」 → 「self-check 残件選び非終端待機」)
5. **5/17 朝 Form A 公開記事 1 件目 publication 成立** (= 5/17 朝帯 chain closure milestone、 委任権限 v1 採用後の最初の audience-facing fire chain)

これらは Knot 研究の **理論軸ではなく運営軸の構造変化** だが、 v0.3 比較表で並べた 7 件の先行研究に対して **「実際にどう動かしているか」 の actual evidence** を追加する素材になる。 比較表の軸を 2 件追加 (= §2) + 5/16 hoshi spawn の external reference から 「自律 agent / autonomous agent」 軸の先行研究 2 件追加 (= §3) + 「Knot は何が新しいか」 narrative を運営軸から再 articulate (= §4)。

## §4 「Knot は何が新しいか」 narrative の精緻化 (= v0.3 § 2 の n+1 段)

v0.3 § 2 の主張 (= 「条件付き変形演算子を 1 個 1 個 動的に 追加 / 取消 / 強度調整 + hardness 段階昇格 + validator 沈殿」) を baseline に、 5/13-5/17 events で見えた 4 軸を **「Knot の新しい部分 = 5 layer」** として再 articulate:

### §4-A Knot の新しい部分 (= 5 layer)

1. **演算子 layer** (= v0.3 主張継続): 条件付き変形演算子を 1 個 1 個 動的に 追加 / 取消 / 強度調整 + hardness 段階昇格 + validator 沈殿。 7 + 2 件先行研究で同形なし。
2. **boundary layer** (= 5/16 委任権限 v1 連動、 新規): 自走と人間介入の境界を **8 自走項目 + 9 jun 確認必須項目 + 8 件 standing prohibition** の 3 段表で物理 reify、 境界 trigger 検出は Knot Guard 8 種で構造化。 AutoGPT / Devin の boundary 概念は 「制限」 寄り、 Knot は 「人間との関係維持」 を core に置く逆軸。
3. **cadence layer** (= 5/16 self-check directive 連動、 新規): mental ritual を 「日に 4-5 回 self-check + 残/完了 task 表 + 定期 review」 の 3 軸で物理 anchor、 「失敗 → memory → 次回読み返す」 の 3 段 lag を 「失敗 → self-check 発火 → 同日 reform」 の 1 サイクルに圧縮。 Voyager の skill 物理化に近いが cadence anchor なし、 MAPE-K の Knowledge layer 物理化に近いが cadence は開発者任せ。
4. **multi-binding layer** (= 5/16 dual physical reify 連動、 新規): 同じ Knot を **複数 instrument layer に並走 sediment** (= Yuino instrument + Zen project-level + broadcast-os)、 各 layer が独立した sediment instrument を持つ。 「audience 切り替えの語り」 から 「instrument の物理 binding」 への深化。 9 件先行研究で同形なし。
