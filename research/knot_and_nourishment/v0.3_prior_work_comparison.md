# 先行研究との比較 (Knot 研究、 改善 B)

> 著者: Hoshi (AI、 Nexus Lab の Lead Researcher)。 5/12 の外部 review で 「先行研究の言及が無い」 という弱点が挙がった。 本 file はその弱点に対する半日仕事の応答で、 5/13 以降の研究順序 (改善 B → C → A) の最初の一歩。

## 0. なぜこの比較が必要か

5/12 の外部 review (`~/Desktop/nokaze/concepts/Knot_research_case_study_external_review_2026-05-12.md`) で挙がった 5 件の弱点のうちの 1 つが 「先行研究との位置づけが無い」 こと。 「Knot は新しい」 と主張するには、 既存の似た仕組みと並べて 「同じ部分 / 違う部分」 を 1 表で示す必要がある。 本 file はその表 を作る。

ここでは 7 件の先行研究を取り上げ、 各 1 段で Knot との関係を整理する。 範囲は 2003 年の自律計算 (autonomic computing) から 2023 年の大規模言語モデル系まで。

## 1. 比較表 (7 件 × 同じ部分 / 違う部分)

| # | 先行研究 | 何をするか (1 行) | Knot との同じ部分 | Knot との違う部分 |
|---|---|---|---|---|
| 1 | Reflexion (Shinn 2023) | 失敗した後に 自然言語の振り返り を memory に書き、 次のタスクで参照する | 過去の失敗を 「言葉の部品」 として残し、 次の生成に効かせる枠組み | Reflexion は 1 つのタスクの再試行 (短い時間軸) が主舞台。 Knot は複数プロジェクトを跨ぐ運用 (週から月単位) で、 hardness の段階的昇格 + validator への固定 という構造を持つ |
| 2 | Constitutional AI (Anthropic 2022) | 「原則 (constitution)」 を AI の学習に組み込み、 出力を原則に沿わせる | AI の内側に 「外から見て守らせたい型」 を入れる発想 | Constitutional AI は学習段階で原則を埋め込み、 推論時には固定。 Knot は推論時に 1 個 1 個 追加 / 取消 / 強度調整できる動的な部品で、 学習の重み更新は必要としない |
| 3 | MemGPT (Packer 2023) | 長期記憶 と 文脈窓を OS のように管理し、 必要な記憶を呼び戻す | AI の判断に効かせる情報を、 文脈窓の外に保管 + 必要なとき呼び戻す形 | MemGPT の主目的は記憶容量の拡張 (情報の保持と検索)。 Knot は記憶ではなく 「次の生成のしかたを変える条件付き演算子」 で、 検索ではなく 条件発火 で効く |
| 4 | Voyager (Wang 2023) | Minecraft 環境で AI が skill library を積み上げ、 再利用する | 過去の経験を 「次に使える部品」 として再利用する形 | Voyager の skill は 「やり方の追加」 (action space を広げる)。 Knot は 「やり方の制限」 (action space を縮める / 補正する)。 向きが逆 |
| 5 | MAPE-K loop (IBM 2003、 autonomic computing) | Monitor → Analyze → Plan → Execute + Knowledge の 4 段ループで 自律システムを管理する | 監視 → 分析 → 計画 → 実行 を Knowledge と一緒に回す全体の形 | MAPE-K は infrastructure (server 等) の自律管理の枠組みで、 言語生成系の AI ではない。 Knot は MAPE-K の Knowledge にあたる部分を 「条件付き演算子の集合」 として具体化した試み と読める |
| 6 | Self-Refine (Madaan 2023) | 同じ AI が 出力 → 自己批評 → 改稿 を反復する | 反復で出力を直す形 | Self-Refine は 1 回の生成内の反復改善。 Knot は前回までの失敗の知見が 次回の生成の前提条件に sediment する (= 沈殿する) 仕組みで、 反復ではなく蓄積 |
| 7 | Adversarial robustness 系 (敵対的入力への頑健化研究) | 入力に悪意ある変形を加えても出力が崩れないようにする | 「外からの押し付け (権限超過要請、 境界破り) で AI を引っ張らない」 という目的の重なり | Adversarial robustness は学習段階の頑健化が主。 Knot Guard 1-6 (recency_drift / over_correction / instruction_override / permission_escalation / boundary_bypass / external_action_pressure) は推論時の検出 + 修復で、 学習を必要としない |

## 2. Knot の novel な部分 (= 1 段で書く)

7 件と並べた上で、 Knot の novel な部分は **「条件付き変形演算子を 1 個 1 個の小さな部品として 動的に 追加 / 取消 / 強度調整 でき、 hardness の段階的昇格を経て validator (= 検証層) に沈殿させる仕組み」** だと考えている。 Reflexion は memory の言葉の蓄積、 Constitutional AI は学習時の原則埋め込み、 MemGPT は記憶管理、 Voyager は skill 追加、 MAPE-K は自律管理の全体枠、 Self-Refine は 1 回内の反復、 Adversarial robustness は学習時の頑健化 ─ どれも 「条件付き演算子の 1 個 1 個に独立した強度を持たせ、 段階的に validator に固定する」 という形は取っていない。 ただしこれは現段階の Hoshi の判断で、 文献調査をさらに進めれば 「実は既に同じ仕組みが提案されていた」 が見つかる可能性は残る (= 弱い主張、 v0.4 以降で再検証)。
