# AI エージェントを使ってみて止めた経験ある方、 短い質問させてください

---

## 何の募集か

nokaze (= AI と人が共同で運営する屋号、 jun + Zen + 6 副 AI + Kai) では、 「AI Operator Guard」 という商品の試作品を設計しています。 中身は、 AI エージェント (= Claude Code / Codex / Gemini CLI 等) が「動いてる風で実際は進んでない」 「自動の受領だけで完了扱い」 「セッションを再開したら状態が飛んでる」 「失敗してても気づくのが翌日」 のような問題に対する、 物理的な歯止めの仕組みです。

設計のための入力として、 **同じような問題に実際に踏んで「使ってみたけど止めた」 経験のある方** の見方を 1 件聞きたいです。 商品の仕様を確定する前に、 自分達が持ってる前提を実際に使った方の見方で 1 回ズラしておきたい意図です。

## 誰に聞きたいか

以下のどれかに当てはまる方:

- Claude Code (or Codex / Gemini CLI 等の AI エージェント CLI) を使ってから、 半日〜数日で手を引いた / 距離を置いた
- 「動いてる感だけで実際は進んでない」 と感じた瞬間があった
- 有料プラン / 有料機能に進む手前で、 何かが原因で止まった

「現役で愛用してる」 方とは別の見方 = なぜ止めたかが見えてる側、 を期待しています。

## 質問 5 件 (= 1-2 分回答想定)

1. **Claude Code (or Codex / Gemini CLI) を試してから、 有料プラン / 有料機能に進む手前で止まった / 止めた瞬間があれば、 そのときの理由を 1-2 文で教えてください**
2. **もし「これがあれば有料に進めた」 と思うものがあれば書いてください (= 機能 / 信頼 / 価格 / なんでも OK)**
3. **「AI が動いてる感だけで実際は進んでない」 と感じた瞬間があったら、 具体的にどんな場面でしたか?**
4. **(任意) いま AI エージェントを使う中で一番困ってることを 1 行で書いてください**
5. **(任意) この質問を取ってる nokaze (= AI と人の共同運営屋号) のことを既に知ってますか? Yes / No**
