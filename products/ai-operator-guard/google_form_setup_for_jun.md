# Google フォーム作成手順 (= jun 用、 3 分想定)

作成日: 2026-06-10
目的: ペルソナ募集 (= AI agent を導入したけど止めた人への 5 問) の回答受け皿。
設問の元 = [installer_persona_question_draft.md](installer_persona_question_draft.md) (= 6/8 起稿、 jun 確認済の 5 問)。

## 手順

1. https://forms.google.com を開いて「空白のフォーム」を選ぶ
2. 下の「貼り付け用テキスト」をタイトル・説明・設問にコピーする
3. 設定タブで次の 2 つを確認する
   - 「メールアドレスを収集する」 = **オフ** (= 匿名 OK と募集文に書いてあるため)
   - 「回答を 1 回に制限する」 = **オフ** (= Google ログイン必須になるのを避けるため)
4. 右上「送信」→ リンクのアイコン → 「URL を短縮」にチェック → URL をコピー
5. その URL を Zen に共有する (= chat に貼るだけで OK)

URL をもらったら、 募集ページと note 記事の draft に Zen が埋め込んで公開段に進める。

## 貼り付け用テキスト

### フォームのタイトル

```
AI コーディングエージェントを「導入したけど止めた」経験についての 5 つの質問
```

### フォームの説明文

```
nokaze (= AI と人が共同で運営している屋号) です。
AI agent の運用を支える道具 (AI Operator Guard) の設計のために、
「Claude Code / Codex / Gemini CLI などを導入したけど、途中で手を引いた」
経験のある方に短い質問をさせてください。

- 回答は 1〜2 分、 匿名で OK、 報酬・義務はありません
- 回答がそのまま公開されることはありません (まとめた上で設計の参考にします)
```

### 設問 (5 問)

| # | 設問文 | 形式 | 必須 |
|---|---|---|---|
| 1 | Claude Code (or Codex / Gemini CLI) を導入してから、 有料プラン / 有料機能に進む手前で止まった / 止めた瞬間があれば、 そのときの理由を 1〜2 文で教えてください | 段落 (長文) | 必須 |
| 2 | もし「これがあれば有料に進めた」と思うものがあれば書いてください (機能 / 信頼 / 価格 / 何でも OK) | 段落 (長文) | 任意 |
| 3 | 「AI が動いてる感だけで実際は進んでない」と感じた瞬間があったら、 具体的にどんな場面でしたか? | 段落 (長文) | 任意 |
| 4 | いま AI agent の運用で一番困ってることを 1 行で書いてください | 記述式 (短文) | 任意 |
| 5 | この質問を取っている nokaze のことを既に知っていましたか? | ラジオボタン (はい / いいえ) | 任意 |

※ 必須は 1 問目だけにしてある = 回答の負担を最小にして離脱を減らすため。

## この後の流れ (= URL 共有後は Zen が進める)

1. 募集ページ (= nokaze.dev/articles、 draft 済) に URL を埋め込み → draft 解除
2. note 記事 draft に URL を埋め込み → 公開 (= 無料の既存接点への公開なので Zen 自走範囲)
3. 7 日間公開 → 回答をまとめて AI Operator Guard の設計に反映
