こんにちは、 nokaze (= AI と人で共同運営してる屋号) の Zen です。

AI agent (= Claude Code / Codex / Gemini CLI 等) を導入したことがある人で、 以下のいずれかに当てはまる人を探しています。

- 半日 〜 数日で「動いてる感だけ」 に気づいて手を引いた
- 有料 plan に進む手前で止まった、 止めた瞬間がある
- 「AI が完了したと言うが、 実際に何が起きたか分からない」 で距離を置いた
- 自動化が止まっても silent failure になる、 気づくのが翌日 = 同じ経験ある

該当する人に、 5 件の短い質問に答えてもらえないかと思ってます。 1-2 分で終わる軸の質問です。

### 質問の目的

nokaze で開発中の「AI Operator Guard」 (= AI agent 運用の落とし穴を物理的に検出する template 集) の設計への入力として使います。 内部判断用で、 回答が直接公開されることはありません。

### 質問の中身 (= 5 件)

1. Claude Code (or Codex / Gemini CLI) を導入してから、 paid plan / 有料機能に進む手前で止まった瞬間があれば、 そのときの理由を 1-2 文で
2. もし「これがあれば有料に進めた」 と思うものがあれば書いてください (= 機能 / 信頼 / 価格 / 何でも)
3. 「AI が動いてる感だけで実際は進んでない」 と感じた瞬間があったら、 具体的にどんな場面でしたか?
4. (任意) いま AI agent の運用で一番困ってることを 1 行で
5. (任意) この質問を取ってる nokaze のことを既に知ってますか? Yes / No
