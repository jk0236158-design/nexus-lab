# ローカル Web アプリ 起動手順 (仮置き)

> ⚠️ **仮置きです**。 Yuino のローカル Web アプリの実装は Kai (Aira 実装担当) が `nokaze-aira/` リポジトリで進めています。 実際の起動手順は、 観察試験 (第 1 段階) の中で Kai が起稿予定。 公開判断は 公開判断ゲート (第 6 段階) で公開する / しないを二択で決定 (動いた記録に基づく)。 本ファイルは構造の概要のみです。

## 何が起動するか (仮置き)

Yuino のローカル Web アプリは、 **手元のパソコンで動くブラウザ画面** です。 起動すると、 ブラウザで `http://127.0.0.1:4327/` (仮の port、 実際の値は Kai 確定) を開いて、 判断をまとめる画面 が表示される予定です。

## 前提

- Node.js 20+ (長期サポート版 推奨)
- ターミナル (PowerShell / bash / zsh のいずれか)
- ブラウザ (Chrome / Firefox / Edge / Safari)
- AI エージェントの API キーを 1 つ以上 (Claude / Codex / Gemini のいずれか)

## 起動手順 (公開判断ゲート (第 6 段階) 通過時に確定予定、 仮置き)

```bash
# step 1: パッケージのインストール (npm)
npm install -g @nokaze/yuino  # ※ 実際のパッケージ名は Kai 確定後

# step 2: 初回 setup
yuino init

# step 3: ローカル Web アプリ 起動
yuino start

# step 4: ブラウザで開く
# (起動メッセージに表示される URL を開く、 通常は http://127.0.0.1:4327/)
```

= 上記コマンドは **仮置きです**。 実際のコマンドは Kai が `nokaze-aira/` で確定後、 本ファイルを置き換えます。

## 安全のルール (起動時の動作)

起動時に以下の動作が走ります:

1. ローカルの `~/.local/share/yuino/state/` フォルダに データ 保存
2. `~/.local/share/yuino/audit.jsonl` に全動作を記録
3. `~/.config/yuino/config.json` に設定保存 (API キー含む、 但し API キーは OS の鍵管理に保存推奨)
4. **手元で動くを厳守**: 起動時に外部送信は発生しない、 あなたが承認した後に初めて AI に呼び出し

## トラブルシュート (仮置き)

実際のトラブルシュートは Kai 起稿後に本ファイルに反映。 仮の形:

| 症状 | 確認 |
|---|---|
| `yuino: command not found` | `npm install -g @nokaze/yuino` 完了確認 + PATH 確認 |
| port 4327 が使用中 | 別の port で起動 (`yuino start --port 4328` 等、 仮置き) |
| ブラウザが開かない | 起動メッセージの URL を手動でコピー、 ブラウザに貼り付け |
| API キーエラー | `.env` または OS の鍵管理に入っている API キー確認、 `yuino keys list` で確認 (仮置き) |
