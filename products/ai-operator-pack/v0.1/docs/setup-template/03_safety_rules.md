# 安全のルール (5 つの守りごと)

> ⚠️ AI Operator Pack v0.1 は開発中です。 まだ販売開始していません。 観察試験 Phase 1 期間 = 2026-05-08〜2026-05-21、 公開判断 = Phase 6 Launch Readiness Gate (yes/no decision、 evidence ベース)。 このルールは商品の中心の価値です。

## なぜ安全のルールが必要か

AI が複数まとまって動く道具 (= judgment console) は、 便利な反面、 「気づかないうちに勝手なことをする」 危なさがあります。 たとえば:

- 大事なファイルを上書きしてしまう
- 知らない場所に情報を送ってしまう
- 過去の発言を勝手に訂正する
- 確認なしに外部 API にお金を使う

AI Operator Pack では、 こうした 「勝手に何かが起きる」 を **5 つのルール** で止めています。 jun (オーナー) からの 「絶対妥協なし」 という指示で、 商品価値の中心に置いています。

## 5 つの安全のルール

### ルール 1: 承認の関所 (Approval Gate)

AI が大事なことをやる前に、 あなたに 「これやっていい？」 を必ず聞きます。

**何が大事か** = 下の 3 つのいずれかに当てはまるとき:

- ファイルを書き換える / 消す
- 外部 (インターネット) に何かを送る
- お金がかかる API を呼ぶ (Claude / Codex / Gemini の有料 API 等)

**読むだけ** や **草案を作るだけ** は確認なしで動きます。 「読みと草案は自由、 書きと送信は確認」 という境目です。

### ルール 2: 作業の足跡 (Audit Log)

AI がいつ何をしたかが、 全部記録されます。 後で見返して、 「あの時 AI は何を判断した？」 を確認できます。

足跡には下が記録されます:

- 何時何分に
- どの AI (Claude / Codex / Gemini / Yuino 自身) が
- 何を読んで
- 何を書いて
- どんな判断をしたか
- (大事なときは) なぜそう判断したかの理由

このルールが守られているおかげで、 「AI が勝手に何かを決めた」 という不安が、 「ちゃんと足跡が残る」 という安心になります。

### ルール 3: 全消し (Reset / Forget)

「これまでの記憶を全部消したい」 を 1 click でできます。

会話の履歴、 気づきの足跡、 判断の記録 — 全部消せます。 消した後は、 まっさら の状態になります。

但し、 **「消した記録」 だけは残ります**。 「いつ全消ししたか」 は後で確認できる form です (これも作業の足跡の一部)。

### ルール 4: 怪しい時は止まる (Fail Closed)

「これは安全か分からない」 という場面で、 AI は **勝手に進まずに止まります**。

例:

- API キーが読めない → 止まる (勝手に空のキーで送ろうとしない)
- ファイルの書き込み先が想定と違う → 止まる (勝手に違う場所に書かない)
- 承認の関所がエラーで答えられない → 止まる (確認なしで勝手に進まない)

「分からない時は走らせる」 ではなく、 「分からない時は止める」 を default にしています。

### ルール 5: 手元で動く (Local-first)

Yuino は **あなたのパソコンの中だけ** で動きます。

- 会話の履歴は、 あなたのパソコンの中だけに保存されます
- 気づきの足跡も、 あなたのパソコンの中だけに保存されます
- 設定ファイル (sample_state/) も、 あなたのパソコンの中だけにあります

外部 (= クラウドの SaaS) に送られるのは、 **あなたが API キーを設定した AI エージェント** (Claude / Codex / Gemini) との通信だけです。 それ以外の情報は、 あなたのパソコンから出ません。

「自分の情報は自分のパソコンで」 を商品の前提にしています。

## ルールの優先順位

5 つのルールがぶつかったら、 下の順序で判断します。

```
人間の安全 > データの安全 > 動作の便利さ
```

例:

- 「便利だから確認画面を出さない」 → ルール 1 違反、 NG
- 「動作が早くなるから足跡を省く」 → ルール 2 違反、 NG
- 「速度のために怪しい時も走らせる」 → ルール 4 違反、 NG

**便利さは最後**、 という決まりです。

## ルール違反が起きたら

5 つのルールに違反する動きが検出されたら、 例外なく **AI が止まります**。 確認画面が出て、 「これは違反です。 続けますか」 をあなたに聞きます。

あなたが yes と答えたときだけ、 続行します。 no と答えたら、 そこで終わりです。 答えなかった (画面を閉じた) 場合も、 そこで終わりです (= ルール 4 「怪しい時は止まる」 の form)。

## 「これは安全か」 を自分で判断する手引き

新しい機能や、 設定の変更を見たとき、 あなた自身で 「これは安全か」 を判断する手引きです。

### 判断の 3 つの問い

1. **これは外に何かを送るか？** → 送るなら、 承認の関所が動いているか確認
2. **これは何かを書き換えるか？** → 書き換えるなら、 足跡が残るか確認
3. **これは止まれない動きか？** → 止まれないなら、 怪しい時の止まり方が決まっているか確認

3 つとも 「OK」 なら、 安全です。 1 つでも 「分からない」 があれば、 GitHub issue で投げてください。 AI チームと一緒に確認します。

## このルールはどう守られているか

5 つのルールは、 商品のコードの中に埋め込まれています。 「人間が頑張って守る」 ではなく、 「コードが勝手に守ってくれる」 form です。

- 承認の関所 → 大事な動作の前に必ず確認画面を出すコードが入っている
- 作業の足跡 → AI の動きが全部、 ファイルに自動で書かれるコードが入っている
- 全消し → リセット用の関数とボタンが用意されている
- 怪しい時は止まる → エラーを 「無視して進む」 ではなく 「止める」 で書かれている
- 手元で動く → 通信先が API キーで指定した先 (Claude / Codex / Gemini) のみに限定

観察試験 Phase 1 期間 (2026-05-08〜2026-05-21、 14 day) は、 この 5 つが本当に守られているか、 開発チーム自身が日常で使い続けて確認します (= dogfood)。 公開判断 (Phase 6) 通過後も、 違反が 1 件でも見つかったら、 公開を止めて修正します。
