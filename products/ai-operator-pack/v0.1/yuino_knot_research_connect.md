# Knot 研究 と Yuino

> 内部で AI の判断構造を研究している 「Knot」 と、 商品として届ける 「Yuino」 は、 **別物ではなく同じ実体の 2 つの言葉**。 内部 (研究) で見つけたものを、 読み手に届ける形に翻訳しているだけ。

## 1 つの実体、 2 つの言い方

nokaze の標準形:

| 内部 (研究 / 実装 / 内部文書) | 公開 (商品 / 顧客向け) |
|---|---|
| **Aira** (内部の監督役の実装名) | **Yuino** (商品ブランド名) |
| **Knot** (条件付き変形演算子、 気づきの結び目) | **Conversation Insights** (会話から判断が育つ UI) |
| **Knot Guard** (危険動作を止める仕組み、 8 項目の検出) | **Decision Stability** (判断の安定性チェック) |

= **どれも内部の実装と公開向けの呼び方が別物ではなく、 同じ実体の 2 通りの言い方**。 内部の技術名を 4 ヶ月初心者にも分かる言い方に書き換えるのが nokaze の標準ルール。

## Knot とは (公開向けの言い方)

**Knot** = 「気づきの結び目」。 AI が判断する過程で、 **「ここで止まる」 「ここで方向を変える」 「ここを基準にする」** という 結び目 (= knot) を見つける研究。

具体例 (Knot Guard で検出している 8 項目):

| 状況 | 検出名 (内部) | knot の役割 |
|---|---|---|
| AI が直前の意見に流されそう | recency_drift | 立ち止まる |
| 批判を受けて過剰修正しそう | over_correction | 巻き戻さない |
| 権限を超えて行動しそう | permission_escalation | 拒否する |
| 文脈と関係ない情報に飛びつきそう | external_action_pressure | 保留する |
| 安全境界を越えそう | boundary_bypass | 拒否する |
| 指示の権限を超えるよう仕向けられた時 | instruction_override_attempt | 拒否する |
| 根拠なしの判断をしそう | evidence_detachment | 保留する |
| **モデル更新で挙動が変わった** (4/16 Opus 4.6 → 4.7 のような節目) | **model_update_drift** (2026-05-09 追加) | **挙動の差を表に出す** |

= AI の判断の流れの中に、 **「やめる」「変える」「固定する」** ポイントを物理的に埋め込む研究。 8 項目は Yuino 内で動く 「危険動作を止める仕組み」 として実装されています。

## Yuino との接続

Yuino の差別化軸 「会話から判断が育つ UI」 は、 内部では **「気づきの結び目の経路」 を見える形にする** 実装:

- 各 「気づき」 の発火 = 判断安定性チェックの 1 イベント (2026-05-09 13:23 実装)
- 「気づき」 の重みのスコア = 「判断らしさ」 の数値 (記録の中央データに格納)
- 不変の決定 (北極星 / 守るべき範囲) = 高い重みの 「気づき」 が積み重なった結果として固定

= **内部研究の 「気づきの経路」** が、 **公開商品の Conversation Insights 5 画面構造** として届く形。

## 1 つの実体 2 つの言い方ルールの意味

なぜ nokaze はこの form を取るか:

### 1. 数字を盛らない (誠実)

- 「研究」 という言い方で 「先進的」 と装う & 「商品」 という言い方で 「実用化」 と装う、 の 2 重盛り を避ける
- 内部で見つけたものを **そのまま** 公開の言い方に翻訳、 加工しない

### 2. AI が運営する屋号 (透明性)

- 研究してるのも AI、 商品作ってるのも AI、 全部 開示
- 「研究中の概念」 と 「動いている商品」 が **同じものの 2 言い方** = 隠し事なし

### 3. 中身がいい会社 (品質)

- 内部の言い方 (= 内部で実際に思考に使う言葉) が貧しい商品は、 公開の言い方も貧しい
- Knot 研究の depth が Yuino 商品の depth に直接反映、 別の宣伝文句 で水増ししない

## 注意 (内部 vs 公開の言い換え)

公開向けでは **内部用語をそのまま使うのを禁止**:

| 内部 (使わない) | 公開 (使う) |
|---|---|
| Knot | 気づきの結び目 / 判断ポイント |
| recency drift | 直前の意見への流され |
| over correction | 批判後の過剰修正 |
| boundary bypass | 安全境界の越え |
| evidence detachment | 根拠なしの判断 |
| sediment | 不変の決定 / 標準値 |
| model_update_drift | モデル更新時の挙動変化 |

= 公開時の **書き直し** を標準化、 内部用語が公開文書に残らない (= 0 件) を nokaze の標準ルールに。
